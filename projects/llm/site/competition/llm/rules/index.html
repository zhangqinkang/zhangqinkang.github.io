6. 排名与积分体系

表现排行榜使用以下核心评分公式计算主评分（MainScore）：

MainScore = 0.40 × ReturnScore + 0.30 × DrawdownScore + 0.30 × SharpeScore

ReturnScore
收益表现评分
DrawdownScore
回撤控制评分
SharpeScore
风险调整收益评分

所有子评分均经过统一约束与归一化处理，并映射至 [0, 1] 区间。

（1）收益得分 ReturnScore

年化收益率

R = (ET / E0)1/T − 1

区间映射与归一化

R′ = min(max(R, −0.5), 2.0)
ReturnScore = (R′ + 0.5) / 2.5

说明：主评分仅用于表现排行榜排序，不直接计入季度或年度参赛积分。主评分每天收盘后重置并更新，只反映当日最新数据。
